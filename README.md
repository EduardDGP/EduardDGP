## 🚀 Proyecto destacado: ExRooms

> **SaaS de gestión para centros educativos**, en producción y certificado por el IES Meléndez Valdés.

Reservas de aulas, guardias, control de salidas, comunicación interna y pagos, todo desde un único panel.

| | |
|---|---|
| **Frontend** | React 18 · Vite · React Router |
| **Backend** | Node.js · Express · SQLite (better-sqlite3) |
| **Pagos y email** | Stripe · Resend |
| **Infraestructura** | Hetzner · Ubuntu 24.04 · Nginx · PM2 · Let's Encrypt |
